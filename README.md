# 🎃 Responsive Halloween Website

**A responsive Halloween-themed website created to demonstrate my skills in HTML, CSS and JavaScript.**

🎃 Responsive Design • 👻 Animations • 🕸️ Interactive Sliders

---

## 👻 Responsive Halloween Website Using HTML, CSS & JavaScript

- Contains animations when scrolling.
- Smooth scrolling in each section.
- Interactive sliders and carousels.
- Responsive navigation menu.
- Developed first with the Mobile First methodology, then adapted for desktop.
- Compatible with mobile, tablet and desktop devices.
- Clean and pleasant Halloween-themed user interface.

---

## 🛠️ Technologies & Resources

**HTML5 • CSS3 • JavaScript**  
**CSS Grid • Flexbox • Media Queries**

- **[Swiper.js](https://swiperjs.com/)** — sliders and carousels
- **[ScrollReveal](https://scrollrevealjs.org/)** — scroll animations
- **[Boxicons](https://boxicons.com/)** — interface icons
- **[Google Fonts](https://fonts.google.com/)** — Poppins font
